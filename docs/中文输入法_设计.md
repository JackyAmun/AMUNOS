# AMUNOS 中文输入法 设计方案

> 版本 v6.8.1 · 分析交付物（不入本轮代码）· 作者: 设计草案
> 配套既有能力: 内核 `put_cjk_str` / EDIT `wputs-CJK` 已能显示**UTF-8 与 GB2312** 中文;
> `HZK16`(GB2312 全 6763 字点阵) 与 `U2GB.BIN`(Unicode→GB2312 映射) 已在 A: 盘就绪。

---

## 1. 目标与约束

做**拼音输入法**是这一步的推荐落地（理由见 §2）。核心约束是两层：

| 约束 | 现状 | 对 IME 的影响 |
|---|---|---|
| 内核体积 | 50736B / 上限 53248B，余 ~2.5KB | **IME 必须走用户态**，绝不进内核。数据表放 A: 盘文件 |
| 磁盘空间 | A: 已用 1718/2743 簇 ≈ 剩 **~500KB** | 一张 ~50KB 码表放得下，无压力（§6 实测断言） |
| 输入通道 | 真实键盘（模式键/热键）；串口仅 ASCII | 候选选择用**数字/空格**（ASCII），换页用 `-` `/` `=`（ASCII），全程避开串口盲区 |
| 显示 | `put_cjk_str` / `wputs-CJK` 画 16×16 汉字占 2 格 | 候选栏/输入串无需新字库，复用现有渲染 |

选定编码回填：**GB2312 双字节**（与 HZK16 直接对应、体积最小）。IME 不产生 UTF-8，减一层换算。

---

## 2. 输入法选型（拼音 vs 五笔 vs 其他）

| 方案 | 上手 | 覆盖率 | 现有资源匹配 | 追加工作 |
|---|---|---|---|---|
| **拼音** ✅ | 最高 | 全 6763，简体全覆盖 | **GB2312 一级字表本身按拼音排序**，可零字典起步 | 拼音→候选索引 |
| 五笔 | 需学习字形码 | 高、同码歧义少 | 无任何码表 | 需完整 6763 五笔码表 + 拆字规则 |
| 郑码/笔画 | 学习成本高 | 中等 | 无 | 需码表 |

结论：**首推拼音**。两个决定性理由：
1. **GB2312 一级字（区 16–55，3755 字）字典序本就是拼音序。** 因此不引入任何外部词库，也能用一张 **"拼音→一级字区段偏移" 边界表**把候选按拼音序给出——一个零版权、仅 ~1.6KB 的 MVP。（详细见 §4.2）
2. 与已完成的显示链（`put_cjk_str`/`wputs-CJK`）直接对接，不需新字形字库。

五笔留作**可后插的第二模态**：只需把码表换成"编码→汉字"，交互骨架与拼音共用。

## 3. 总体架构（用户态，不进内核）

```
                       ┌──────────────┐
   键盘 ASCII 拼音串 ──▶ │  IME 合成器    │   (独立用户态 ELF, 如 IME.ELF)
                       │  1. 拼音→候选   │
                       │  2. 候选渲染    │ ──▶ put_cjk_str(候选栏, 每字2格)
                       │  3. 命中回填    │ ──▶ 写 GB2312 字节到 [编辑缓冲|stdout]
                       └──────────────┘
                              │
              PY.TAB(A:盘 拼音→候选索引, 可选 DICT.TAB 全字典)
```

组件拆分：
- **IME.ELF**（输入法主体，独立程序）——不依赖 EDIT 即可演示。
- **PY.TAB**（A:盘）——拼音→候选索引数据，`gen_pinyin.py` 生成。
- **两级接入方式**：
  - **方式 A（MVP，零 EDIT 改动）**：`IME` 作为独立命令，打开一个"终端式拼音合成器"。你打拼音 → 状态行出候选 → 数字选择 → 合成区累积 → `ENTER` 把整串 GB2312 写到 **stdout**（可重定向，如 `IME > 中文.TXT`）。**当天可用。**
  - **方式 B（完整，后插）**：在 EDIT 内按热键弹出候选窗，选中字直接写回编辑缓冲当前光标处并触发该行重绘（复用 `WriteTextLine`）。需改 DFLAT 键处理 + 候选窗叠加绘制 + 缓冲位移，属大人改动。

## 4. 数据表设计

### 4.1 拼音音节表（编码层）
把全部拼音音节（无声调去重后 ~410 个）编成 **id 0..409**，存一张 `PYIDX` 表：
- 字符串表: `"a","ai","an",...`（按 id 顺序，\0 分隔）
- 每个音节 id 作为内部编码，压缩比对/映射体积。

### 4.2 方案一: 零字典 MVP —— 用 GB2312 一级字拼音序（推荐先做）
GB2312 区 16~55（0xB0A1~0xD7F9）3755 个一级字**按拼音排序**。构造表：

```
PYRANGE: 每个拼音 → (起始GB码, 区段内偏移量)
  记录数 ≈ 拼音数 ~410，每记录 2×u16 = 4B  → 全表 ~1.6KB
```
查找：对输入拼音 id，取该拼音在**一级字表**涂覆的区段，这段字便按拼音序排列＝候选。多音字天然产生"一个拼音命中一段字"，正是拼音候选语义。**零版权、体积最小、离线可生成。** 不足：仅一级字（覆盖率日常 ~99%），无词语候选。

### 4.3 方案二: 完整拼音字库（要二级字/词语时做）
给 6763 字每字一条"拼音"或多音多拼：`DICT.TAB` ≈ 6763 × ~8B ≈ **~54KB**。加上调序/常用度权重可更智能。体量在 A: 剩余 ~500KB 内（§6 数值）。生成器 `gen_pinyin.py` 可从 U2GB 反查码点再映射音节，或内置一张拼音表。

> **建议**：先落 4.2 的 `PYRANGE` 让输入法"当天能打字"，再按需补 4.3 的增强码表。

## 5. 交互设计

### 5.1 键位（全部 ASCII/控制码，避开串口与模式键）
| 按键 | 动作 |
|---|---|
| a–z | 累积拼音串（gtk 式：输入即查） |
| 空格 | 第 1 候选上屏（首选） |
| 数字 0–9 | 选择第 N 个候选上屏 |
| `-` / `=` 或 `[` `]` | 候选页上/下翻页 |
| `Backspace` | 删拼音串末音节 |
| `Ctrl+Space` (真实键盘) | 方式 B 开关我输入法 / 方式 A 每次 `IME` 启动即进入 |
| `Enter` | 方式 A: 提交合成区整串到 stdout |
| `Esc` | 放弃当前合成/退出 |

### 5.2 界面（复用现渲染，不加部件）
- 编辑区：正常文本，跳过。
- **候选栏**：一行固定状态（如 EDIT 底部、或独立 shell 行为），每候选 2 格汉字 + 前导数字键头：
  ```
  zhong: 1中 2种 3重 4众 5终 6钟 7忠 8仲   ▸ 每页 8 候
  ```
  用 `put_cjk_str`（内核态）或 `wputs-CJK`（EDIT 内）逐字绘制。
- 合成区与候选栏**不侵入文本缓冲**（方式 A 独立进程天然隔离；方式 B 需候选窗软缓冲暂存/恢复，见 §7 风险）。

### 5.3 两种方式的回填差异
- **方式 A**：整串一次性缓冲，ENTER 写入 stdout。`IME > 中文.TXT` 即获得一份 GB2312 中文文件——**可直接呼应本轮中文文件名/内容回环**。
- **方式 B**：选中单字立即在光标处插入 2 字节，改 `currchar` 与指针后触发该行 `WriteTextLine` 重绘（EDIT 已有此路径，v6.8.1 的整字删/DeleteKey 同理）。

## 6. 体积与磁盘实测

| 项 | 大小 | 状态 |
|---|---|---|
| `PYRANGE` 拼音→一级字边界 | ~1.6KB | A: 放得下 |
| `DICT.TAB` 全字库 | ~54KB | A: 放得下 |
| 字库 HZK16 / U2GB.BIN | 已有 | 复用，**不新增** |
| A: 剩余空间 | **~500KB**（2722 簇可用 − 1718 已用，簇 512B） | 充足 |
| 内核增量 | **0**（IME 全用户态） | 不触碰 53248B 红线 |

## 7. 风险与对策

1. **候选栏与文本叠加的软缓冲复原**（方式 B）：在候选窗绘制前 `memcpy` 被覆盖的 cell 字节，取消时写回，再全行重绘。`fb_render` 每帧重画软缓冲，候选窗每次需同步重画或依赖固定位置。
2. **输码与编辑按键冲突**：方式 B 需在 EDIT 按键链最前端拦截（保留空格给首选、Ctrl+Space 开关），改 `DoKeyStroke` 入口。方式 A 独立进程无此问题。
3. **多音/候选排序**：MVP 按 GB2312 拼音序即可；增强再接入频度/词语。
4. **串口无模式键**：候选全用数字/空格/翻页（ASCII），串口可完整驱动所有选择。真实键盘补 Ctrl+Space/Enter 开关。
5. **.TAB 文件装载**：遵循现有 A: 盘文件读取（`fs_read` → 内存缓冲），大小 < 128KB 一次读入无压力。

## 8. 落地路径（建议顺序）

| 阶段 | 内容 | 依赖 |
|---|---|---|
| P1 | 主机侧 `gen_pinyin.py` 生成 `PYRANGE.TAB`（~1.6KB，纯 Python，离线） | 无 |
| P2 | `IME.ELF` 方式 A：终端拼音合成器 + 数字选字 + ENTER 输出 GB2312 | P1；内核无需改 |
| P3 | 验证回环：`IME` 打 "你好" → `> 中文.TXT` → `TYPE` / EDIT 打开显示正确 | 本轮显示链 |
| P4 | 方式 B：EDIT 候选窗 + 写回光标（需大改 DFLAT 键链） | 独立排期 |
| P5 | 可选：`DICT.TAB` 全字库/词语 + 五笔第二模态 | 按需 |

> 本轮（v6.8.1）已交付前三块地基：**中文文件名（含 GB2312 8.3）**、**EDIT 显示 UTF-8/GB2312**、**EDIT 整字安全删**。IME 从此文档起可作为独立后续任务，不改动已完成的显示链路。
