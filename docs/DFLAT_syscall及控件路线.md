# DFLAT syscall 与控件路线

## 定位

DFLAT 是 FreeDOS EDIT 携带的用户态文本窗口/控件框架。按钮、编辑框、列表框、组合框、单选/复选框、滚动条和对话框继续由 DFLAT 绘制并处理输入；AMUNOS syscall 只提供它无法独立完成的内核服务。这样控件可独立演进，避免把窗口控件 ABI 固化到内核。

本次首个 `SYS_DFLAT_*` 子系列处理软件文本光标：将位置、形状和显隐作为一个原子状态管理，并提供状态保存栈，解决 DFLAT 分层窗口、对话框和编辑框间光标不同步的问题。

## syscall ABI（68-73）

| 编号 | 调用 | 约定 |
| --- | --- | --- |
| 68 | `sys_dflat_cursor_set(x,y,shape)` | 一次更新状态；坐标按 80x25 文本屏幕钳制；形状 `0` 下划线、`1` 竖线、`2` 块 |
| 69 | `sys_dflat_cursor_get(out)` | 写入 `out[0..3] = x,y,shape,visible` |
| 70 | `sys_dflat_cursor_push()` | 保存完整状态，最多 50 层；溢出返回 -1 |
| 71 | `sys_dflat_cursor_pop()` | 恢复并弹出最近状态；空栈返回 -1 |
| 72 | `sys_dflat_cursor_visible(visible)` | 显示或隐藏，不丢失位置与形状 |
| 73 | `sys_dflat_cursor_swap()` | 交换栈顶两份保存状态；少于两层返回 -1 |

状态读写及屏幕叠加更新在内核侧关中断完成，避免定时器重绘与用户态光标移动交错。旧的 `SYS_CUR*` 保留给已有程序；DFLAT console backend 已改用新系列。

## 展示程序

`DFLAT` 命令启动 `dflat-demo.elf`。程序复用 EDIT 的 DFLAT 源码和原生对话框资源，展示 EditBox、CheckBox、RadioButton、ListBox、ComboBox、SpinButton、TextBox、按钮和焦点导航。光标 syscall 的当前坐标/形状/显隐在说明控件中呈现。程序独立于 EDIT 主入口，不触及图形 GUI。

## 后续建议

1. **P0：兼容性与边界**：为光标 syscall 增加可重复的边界用例，包括栈空/满、显隐后恢复、窗口切换、中文双宽字符旁的光标，以及鼠标叠加重合时的还原。
2. **P1：控件行为**：先补齐焦点进入/离开协议、Tab 顺序和禁用控件语义；统一按键与鼠标动作生成 DFLAT 消息，避免每个控件重复处理。
3. **P1：编辑体验**：完善 TextBox/EditBox 的选择范围、剪贴板、多行插入、撤销/重做及 UTF-8/GB2312 光标列宽计算；以字符边界而非字节偏移作为可见列位置。
4. **P2：列表类控件**：为 ListBox/ComboBox/SpinButton 明确滚动位置、选中项、边界键行为和可查询状态，列表较长时采用可视窗口而非重绘全表。
5. **P2：资源与可访问性**：增加一致的控件默认值/校验/必填状态、快捷键冲突检查、焦点指示与帮助文本接口；保持应用可在纯文本模式操作。
6. **P3：健壮性**：新 syscall 验证用户指针、长度和缓冲区范围；约定错误码及结构体版本，避免应用传入无效指针使内核直接解引用。

其中第 6 项是当前 syscall ABI 的重要安全后续：本系列延续项目现有的直接用户指针约定，不能视为已经完成用户地址验证。扩大 syscall 前应先引入统一的用户区间检查，而不是让各控件接口各自猜测边界。
